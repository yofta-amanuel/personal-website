# Personal Website (Portfolio)

Course: Internet Programming I (INSY3061), Wollo University, Kombolcha Institute of Technology.

## Description
A responsive personal portfolio with Home, About, Skills, Projects, Education and Contact sections.

## Technologies
- HTML5 (semantic: header, nav, main, section, article, footer, dialog)
- CSS3 (variables, Flexbox, Grid, media queries, dark theme)
- JavaScript (vanilla, no libraries)
- Google Fonts: Space Grotesk
- Git and GitHub

## Features
- Responsive navigation with mobile menu
- Dark/light theme saved in localStorage
- Time-based greeting
- Animated skill bars
- Project filter and details modal
- Contact form with HTML and JavaScript validation

## How to run
1. Download or clone the repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
